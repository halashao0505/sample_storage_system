# 10 局域网双屏部署

## 1. 最终结构

```text
                    ┌─────────────────────────────────┐
                    │ 平台主机                          │
XAFS 控制电脑 ────▶ │ 3200：接收 XAFS/XRD JSON         │
XRD 控制电脑 ─────▶ │ 3101：XAFS 只读网页              │
                    │ 3102：XRD 只读网页               │
                    └──────────────┬──────────────────┘
                                   │ 局域网
                  ┌────────────────┴────────────────┐
                  ▼                                 ▼
          XAFS 显示屏电脑                    XRD 显示屏电脑
          打开 主机IP:3101                  打开 主机IP:3102
```

只有平台主机运行 Python 接口服务和 Node 网页服务。两台显示屏电脑只需浏览器，不需要 Python、Node.js、SDK，也不需要复制整个项目。

## 2. 平台主机要做什么

1. 确保平台主机、两台控制电脑、两台显示屏电脑在同一个可信局域网；
2. 双击 `启动局域网样品平台.bat`；
3. 输入一段写入令牌；
4. 保持弹出的 API、XAFS、XRD 三个命令窗口运行；
5. 确认防火墙允许可信“专用网络”访问 TCP 端口 `3200`、`3101`、`3102`。

`3200` 仅给 XAFS/XRD 控制程序发送状态数据。`3101`、`3102` 仅给显示屏浏览器看界面。

## 3. 显示屏电脑要做什么

把以下任意一个小脚本复制到对应显示屏电脑后双击：

- `打开XAFS屏幕.bat`：输入平台主机 IP，打开 XAFS 页面；
- `打开XRD屏幕.bat`：输入平台主机 IP，打开 XRD 页面。

例如平台主机 IP 是 `192.168.100.148`：

```text
XAFS 屏幕：http://192.168.100.148:3101/
XRD  屏幕：http://192.168.100.148:3102/
```

显示屏脚本只负责打开浏览器，不会启动新的后端，也不会向设备发任何控制命令。因此两块屏幕可以同时启动。

## 4. 两台控制电脑怎样上传数据

XAFS 控制程序使用：

```python
client = SamplePlatformClient(
    "http://平台主机IP:3200",
    api_token="启动局域网样品平台.bat 中输入的同一个令牌",
)
client.publish_snapshot("xafs", frame)
```

XRD 仅把技术类型改成 `xrd`：

```python
client.publish_snapshot("xrd", frame)
```

每个控制程序都创建自己的 SDK Client，并每 3 秒发送一帧。XAFS 和 XRD 的连接、断连计时、最后状态完全分开。

## 5. 选择哪个 IP

平台主机有多个网卡时，选择与显示屏电脑处于同一网段的 IPv4 地址：

- 显示屏是 `192.168.100.xxx`，平台主机填 `192.168.100.xxx`；
- 显示屏是 `192.168.8.xxx`，平台主机填 `192.168.8.xxx`。

不要使用 `127.0.0.1`，它只代表“当前这台电脑”；也不要使用 VPN、虚拟网卡或不属于实验室局域网的地址。

## 6. 断连时的表现

- 控制电脑停止上传超过 10 秒：对应 XAFS 或 XRD 页面显示“通讯中断”；
- 另一种谱仪仍继续正常显示；
- 显示屏电脑与平台主机断网：该显示屏的浏览器无法刷新，可通过浏览器报错和平台主机页面区分；
- 恢复网络并重新发送 JSON 后，网页约 3 秒内恢复在线。

## 7. 安全边界

- 不将 3200/3101/3102 端口暴露到公网；
- 3200 写接口必须设置令牌；
- 令牌只交给 XAFS/XRD 控制电脑，不交给只读显示屏；
- 网页没有高压、快门、运动、上样或下样控制接口。
