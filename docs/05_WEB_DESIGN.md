# 05 网页信息架构与视觉规范

## 1. 视觉方向

关键词：**专业、安静、精确、实验室、现代数据平台**。

视觉参考取 Linear 的信息密度、Vercel 的克制、ChatGPT Usage 的统计层级和 Grafana 的指标组织方式，但不照搬任何一个产品。

明确避免：

- 传统蓝色顶部导航 + 密集 Bootstrap 表格；
- 霓虹蓝光、发光边框、大面积渐变；
- 纯装饰性 3D、粒子动画和深色科技大屏；
- 所有卡片同等强调导致没有视觉重点；
- 只靠红绿颜色表达状态。

## 2. 1920 × 1080 首页框架

```text
┌──────── 240 ────────┬──────────────────────────── 1680 ─────────────────────────────┐
│ ZJUT Sample Platform│ 顶栏 72：搜索、日期、同步状态、用户                              │
│                     ├──────────────────────────────────────────────────────────────────┤
│ Overview            │ 页面标题：今日测试概览                            实时数据       │
│ Queue          11   │                                                                  │
│ Samples             │ KPI × 5：样品 / 完成 / 测试次数 / 测试时长 / 待测试             │
│ History             │                                                                  │
│ Analytics           │ ┌──────────────────────────┬────────────────────┐                │
│                     │ │ 测试趋势图（约 2/3）      │ 谱仪运行（约 1/3） │                │
│ Devices             │ │ 全部/XAFS/XRD + range     │ XAFS、XRD 当前任务 │                │
│ Settings            │ └──────────────────────────┴────────────────────┘                │
│                     │ ┌──────────────────────────┬────────────────────┐                │
│                     │ │ 最近测试记录（约 2/3）    │ 待测试队列（约 1/3）│                │
│ 系统运行正常        │ └──────────────────────────┴────────────────────┘                │
└─────────────────────┴──────────────────────────────────────────────────────────────────┘
```

布局尺寸：

- 左侧导航：240 px；
- 顶栏：72 px；
- 主内容最大宽度：1560 px；
- 页面边距：28–32 px；
- 卡片间距：16 px；
- 卡片圆角：12–14 px；
- 卡片阴影很弱，以 1 px 边框为主。

## 3. 设计变量

### 颜色

| Token | 值 | 用途 |
| --- | --- | --- |
| `--page-bg` | `#F5F7FA` | 页面背景 |
| `--surface` | `#FFFFFF` | 卡片、抽屉、弹窗 |
| `--surface-muted` | `#F8FAFC` | 表头、输入框、次级区域 |
| `--text-primary` | `#17202E` | 标题、核心数值 |
| `--text-secondary` | `#687386` | 说明、标签 |
| `--text-tertiary` | `#9AA4B2` | 时间、占位符 |
| `--border` | `#E5E9F0` | 分隔和卡片边框 |
| `--brand` | `#356AE6` | 主操作、链接、测试中 |
| `--success` | `#1C9B62` | 完成、在线 |
| `--warning` | `#D99116` | 暂停、需关注 |
| `--danger` | `#D94A4A` | 失败、错误 |
| `--neutral-status` | `#6B778A` | 待处理、取消 |
| `--sidebar` | `#182234` | 唯一深色大区 |

每个状态都使用“图标/圆点 + 中文文字 + 淡色背景”，颜色只是辅助。

### 字体

```text
Inter / SF Pro Display / Segoe UI / Microsoft YaHei / system-ui
```

| 层级 | 大小 | 字重 |
| --- | --- | --- |
| 页面标题 | 28–30 px | 650 |
| KPI 数值 | 28–34 px | 650 |
| 卡片标题 | 15–16 px | 600 |
| 正文 | 13–14 px | 400 |
| 表格 | 12–13 px | 400/550 |
| 辅助文字 | 11–12 px | 400 |

数字使用 tabular numerals，避免进度和时间变化时抖动。

### 间距与圆角

采用 4 px 基础网格：`4, 8, 12, 16, 20, 24, 32, 40`。

- Card：14 px；
- Button/Input：8–9 px；
- Tag：6 px；
- Drawer/Modal：16 px；
- 主按钮高度：38–40 px；
- 表格行高：48–52 px。

## 4. 导航与页面层级

### 左侧导航

```text
工作区
  概览 Overview
  排队列表 Queue        11
  样品档案 Samples
  测试记录 History
  数据统计 Analytics

系统
  设备状态 Devices
  系统设置 Settings
```

- 一级页面不超过 7 个；
- 当前项用浅蓝背景、左侧 3 px 指示条和白色文字；
- 底部固定展示平台、数据库和 XAFS 来源的组合状态入口；
- 设备状态页面也保持只读，不出现控制按钮。

### 顶栏

- 全局搜索：样品编号、名称、申请人、课题组；
- 全局范围切换：全部谱仪 / XAFS / XRD / 具体设备；
- 最近同步时间；
- 通知入口只显示需要人工处理的异常；
- 当前用户和角色。

## 5. 首页组件

### KPI Card

每张卡只包含一个主指标：标签、数值、对比/解释、语义图标。避免在一张 KPI 卡放多个同级数字。

首版五张：

1. 今日样品；
2. 今日完成；
3. 今日测试次数；
4. 今日累计测试时长；
5. 当前待测试。

### Trend Chart

- 指标切换：样品数、测试次数、测试时长、完成率；
- 范围切换：今日、7 天、30 天、自定义；
- 今日按小时，7/30 天按天；
- hover 显示时间、值和同比/环比；
- 没有数据时显示空状态，不绘制虚假曲线；
- 颜色和单位随指标切换。

### Instrument Live Board

视觉权重仅次于趋势图。不是只有一张全局“当前样品”，而是按设备显示紧凑卡片；首版至少同时展示 XAFS 和 XRD。每张卡包含：

- 样品编号、名称、申请人、课题组；
- 测试类型、设备和操作员；
- 文字状态与状态更新时间；
- completed/total 可用时显示百分比；
- 开始时间、已运行、预计剩余；
- 当前能量/角度、步数等已确认字段；
- 只提供“查看详情”，不提供设备控制。

设备专属信息放在卡片下半部分：

- XAFS：当前 energy/theta、completed/total points、ROI count rate；
- XRD：当前 2Theta、步数、曝光时间、样品工位；
- 设备空闲：显示最近完成和下一任务；
- 设备离线：显示最后可信状态和离线时长，不把任务改成失败。

来源断开时，卡片变为琥珀色提示：“状态暂不可确认，最后更新 09:24:32”，保留最后可信值但停止动画。

### Queue Preview

按 XAFS/XRD 分组或切换显示。每行显示设备、队列号、任务/样品编号、测试类型、预计耗时、预计开始时间。首页不允许拖动；去 Queue 页面调整。

### Recent Records

列：样品编号与名称、申请人、测试类型、开始时间、耗时、状态、查看。失败行不整行染红，只在状态和错误提示处强调。

## 6. Queue 页面

顶部：技术类型、设备、日期、状态、测试类型筛选；右侧为“登记任务”。

主体先按设备选择队列，不能把 XAFS 与 XRD 任务放在同一条实际执行队列。选中队列后分两栏：

- 左侧 72%：可排序队列表格；
- 右侧 28%：选中任务的参数、样品风险说明、预计时间和审计摘要。

拖动排序后先显示变更预览，再提交；若 `version` 冲突则刷新并明确提示，不静默覆盖另一名实验员的调整。

## 7. Samples 页面

- 顶部搜索 + Filter chips + 保存视图；
- 表格提供“有 XAFS 任务 / 有 XRD 任务 / 同时有两类任务”筛选，但样品本身不贴死谱仪类型；
- 表格与卡片视图可在后期切换，首版只做高质量表格；
- 点击一行打开右侧 440–520 px Drawer；
- Drawer 用于快速查看，完整生命周期和文件进入详情页；
- 空值显示 `—`，不显示 `null / None`。

## 8. Sample Detail 页面

```text
标题区：样品编号、名称、状态、申请人、创建时间
├─ Overview：基本信息、风险说明、备注
├─ Test Tasks：所有计划任务
├─ Runs：每次实际执行
├─ Timeline：完整事件时间线
└─ Files：原始、规范化、导出、报告
```

不同 run 必须清楚分组，不能把多次测试的参数和结果混在一张表中。

详情页的结果查看器按 technique 加载：

- XAFS viewer 使用 energy/theta 横轴和 ROI 标量；
- XRD viewer 使用 2Theta 横轴和 intensity，提供原始 GK 文本/文件下载；
- 公共详情只显示相同语义字段，不用一张超宽表塞入两套专属参数。

## 9. History 与 Analytics

History 是可追溯的执行记录，不是 Samples 的重复列表。默认显示 technique/设备列，支持 XAFS/XRD 筛选。点击记录先开 Drawer，再进入对应技术类型的完整 run 页面。

Analytics 采用指标卡 + 趋势图 + 分布图三层，不在一页堆十几张小图。默认展示：

- 样品/测试趋势；
- 平均等待与测试时长；
- 成功率；
- 设备利用率；
- 测试类型和课题组分布。

所有指标旁提供定义说明，例如利用率的分母是“配置工作时段”而不是 24 小时。跨谱仪只合并样品数、任务数、等待、耗时和成功率；XAFS ROI 与 XRD intensity 不放在同一统计曲线。

## 10. 组件状态

所有交互组件必须设计：

- default；
- hover；
- pressed；
- focus-visible；
- disabled；
- loading；
- error（输入/请求失败）；
- empty（无数据）；
- stale（数据过期，仅状态组件）。

按钮不通过改变布局表现 loading；输入错误提供文字说明；焦点环对键盘用户可见。

## 11. 响应式

| 宽度 | 行为 |
| --- | --- |
| `≥1440` | 完整 240 px 侧栏、五 KPI、2/3 + 1/3 双栏；右栏并列/堆叠两台谱仪 |
| `1024–1439` | 侧栏压缩或可收起，KPI 3+2，主面板可上下排列 |
| `768–1023` | 抽屉式导航，2 列 KPI，表格横向滚动 |
| `<768` | 单列；只保留查看与轻量登记；复杂排队调整提示使用桌面端 |

平台以实验室桌面浏览器为主，但不能在窄屏直接破版。

## 12. 动效与可访问性

- 卡片 hover 位移不超过 1 px；
- 状态更新采用淡入，不持续闪烁；
- 当前测试圆点可做低频 pulse，来源断开立即停止；
- 支持 `prefers-reduced-motion`；
- 正文对比度满足 WCAG AA；
- 图表同时提供可读摘要/表格；
- 所有图标有文本或可访问名称；
- 键盘可访问筛选、抽屉、表格操作和弹窗。
